# 📖 leituras

Projeto desenvolvido em **HTML, CSS e JavaScript** para meu projeto **leituras**. O objetivo principal é estimular meu hábito de leitras.
O site consome dados diretamente de uma planilha **Google Sheets** via **API**, permitindo atualização dinâmica do conteúdo.

<a target="_blank" href="https://igorlazzaretti.github.io/leituras/">Confira o Projeto Aqui 📚</a> <br>
<a target="_blank" href="https://flic.kr/s/aHBqjCwBLS">Veja fotos do Projeto 📸</a>

---

## 🚀 Tecnologias Utilizadas

**Front-End:** HTML, CSS, Bootstrap e JavaScript
**Back-End e Dados:** API Google Sheets

### Principais recursos:
- 🎨 **Design:** Criação e Escolha das Imagens de Fundo;
- 🧩 **Organização:** Estrutura limpa e modular com HTML, CSS e Bootstrap;
- 🔗 **Dados:** Consumo de informações via API do Google Sheets;
- 📱 **Layout Responsivo:** Compatível com dispositivos móveis.
